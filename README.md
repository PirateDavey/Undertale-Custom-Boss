# Undertale-Custom-Boss
BossTextMod is a text and boss mod for Undertale, made as a script for UndertaleModTool. It rewrites selected in-game dialogue and adds a custom boss, Captain Crumb, a tiny, overconfident baker-captain who replaces an early enemy with his own name, stats, battle dialogue, and flavor text. To install, back up your own copy of data.win, open it in UndertaleModTool, run BossTextMod.csx from the Scripts menu, then save and launch the game. The mod doesn’t include any game files, so you need your own legal copy of Undertale. Boss stats, dialogue, and text swaps are all editable in the config section at the top of the script. Any edit the script can’t apply to your game version is skipped and reported rather than breaking your file.
